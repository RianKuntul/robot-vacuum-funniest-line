The Robot Vacuum's Funniest Excuse: one line in which a robot vacuum
explains why it missed a spot.

> That spot was not missed — I unionised with the dust. We both agreed the floor was fine as it was.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
